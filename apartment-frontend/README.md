# Apartment Frontend

Frontend application for the Apartment application.

The frontend is built with Next.js and provides a responsive interface for browsing apartments, filtering listings, viewing apartment details, pagination, and displaying apartment images.

---

## Features

- Browse all apartments
- View apartment details by ID
- Filter apartments by:
  - City
  - Minimum price
  - Maximum price
  - Number of bedrooms
- Pagination
- Responsive apartment listing
- Responsive apartment details page
- Apartment image gallery
- Display apartment information:
  - Title
  - Description
  - Address
  - City
  - Price
  - Bedrooms
  - Bathrooms
  - Area
  - Images
  - Verification status
  - Contact phone number
- Loading skeletons
- Error handling
- Empty state handling
- Search and filter reset
- URL-based filters and pagination
- Previous and next page navigation
- Mobile, tablet, and desktop responsive design
- Environment support:
  - `dev`
  - `sit`
- Environment-based API configuration
- Integration with the NestJS backend
- Docker support
- Docker Compose support
